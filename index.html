Thực hành Git & GitHub

Giới thiệu

Đây là trang web đơn giản dùng để thực hành quản lý mã nguồn với Git và GitHub.

Các lệnh Git đã dùng

  • git init: khởi tạo repository
  • git add: đưa file vào vùng staging
  • git commit: lưu lại một phiên bản
  • git branch, git checkout: làm việc với nhánh
  • git merge: gộp nhánh
  • git push: đẩy mã nguồn lên GitHub
